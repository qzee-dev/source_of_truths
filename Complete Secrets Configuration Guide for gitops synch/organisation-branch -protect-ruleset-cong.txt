If you give a Senior Engineer Write permission, they can:
 ✅ Create branches
 ✅ Push commits to branches
 ✅ Create PRs
 ✅ Review PRs
 ✅ Merge PRs (subject to branch protection)
But the risk is:
.github/workflows/
``
Production-Grade Protection
Protect the main branch with rules such as

✓ Require pull request
✓ Require 2 approvals
✓ Require status checks
✓ Dismiss stale approvals
✓ Require review from Code Owners
``
Then create a CODEOWNERS file:

# Platform team owns CI/CD

.github/workflows/ @coreinfra-labs/platform
terraform/         @coreinfra-labs/platform
helm/              @coreinfra-labs/platform

# Backend

apps/backend/      @coreinfra-labs/backend

# Frontend

apps/frontend/     @coreinfra-labs/frontend
