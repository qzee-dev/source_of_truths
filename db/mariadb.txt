If you want to build exactly what is in the YAML from scratch, the manual process is simply the same commands executed one by one instead of through Systems Manager.

Step 1: Install MariaDB
sudo yum update -y

sudo amazon-linux-extras enable lamp-mariadb10.2-php7.2

sudo yum install -y mariadb-server

sudo systemctl start mariadb

sudo systemctl enable mariadb


Verify:

systemctl status mariadb

Step 2: Secure MariaDB
sudo mariadb-secure-installation [ follow prompt to secure your database]


Step 3: Verify MariaDB
mysql -u root -ppassword123 -e "SELECT version();"

Step 4: Create the Sports Cars Database

Create database:

mysql -u root -ppassword123 -e "CREATE DATABASE sportscars;"


Create user:

mysql -u root -ppassword123 -e "CREATE USER 'caradmin'@'localhost' IDENTIFIED BY 'caradmin123';"


Grant permissions:

mysql -u root -ppassword123 -e "GRANT ALL PRIVILEGES ON sportscars.* TO 'caradmin'@'localhost';"

verify creation:
mysql -u root -p -e "SELECT User, Host FROM mysql.user WHERE User='caradmin';"
sudo mariadb -e "SELECT User, Host FROM mysql.user WHERE User='caradmin';"


Flush privileges:

mysql -u root -ppassword123 -e "FLUSH PRIVILEGES;"

Step 5: Create the Cars Table
mysql -u root -ppassword123 sportscars


Then run:

CREATE TABLE cars (
    id INT AUTO_INCREMENT PRIMARY KEY,
    make VARCHAR(50),
    model VARCHAR(50),
    year INT,
    horsepower INT,
    top_speed_mph INT,
    price_gbp DECIMAL(10,2),
    engine_type VARCHAR(50)
);

If by "attach it to a distributed system" you mean your EC2-hosted MariaDB will be used by multiple application servers (for example Spring Boot applications running on several EC2 instances), then the simplest architecture is:

                +------------------+
                | Load Balancer    |
                +--------+---------+
                         |
        +----------------+----------------+
        |                                 |
+-------v-------+                 +-------v-------+
| Spring Boot 1 |                 | Spring Boot 2 |
| EC2 Instance  |                 | EC2 Instance  |
+-------+-------+                 +-------+-------+
        \                               /
         \                             /
          \                           /
           +------------+------------+
                        |
              +---------v---------+
              | MariaDB on EC2    |
              | sportscars DB     |
              +-------------------+

Step 1: Create the database on EC2

Follow exactly the MariaDB installation and sportscars database setup from your YAML.

Step 2: Allow network access

Open the EC2 security group hosting MariaDB:

Port: 3306
Source: Security Group of Spring EC2 instances


Avoid opening:

0.0.0.0/0 -> 3306


in production.

Step 3: Get the EC2 private IP

On the MariaDB server:

hostname -I


Example:

10.0.1.100


Your Spring applications will use this IP.

Step 4: Configure MariaDB to accept connections

Edit:

sudo vi /etc/my.cnf
cd   my.cnf.d 
vim mariadb-server.cnf 

Change:

bind-address=127.0.0.1


to:

bind-address=0.0.0.0

 sudo my_print_defaults --mysqld

Restart:

sudo systemctl restart mariadb

Step 5: Create a Spring datasource user

You already have:

CREATE USER 'caradmin'@'localhost'
IDENTIFIED BY 'caradmin123';

mysql://caradmin:caradmin123@YOUR_EC2_PUBLIC_IP:3306/sportscars
mysql -h 16.171.176.37 -P 3306 -u caradmin -p sportscars
mysql -h 16.171.176.37 -P 3306 -u root -p sportscars

For remote Spring servers:

CREATE USER 'caradmin'@'%'
IDENTIFIED BY 'caradmin123';

GRANT ALL PRIVILEGES
ON sportscars.*
TO 'caradmin'@'%';

FLUSH PRIVILEGES;

Step 6: Configure Spring Boot

In application.properties:

spring.datasource.url=jdbc:mariadb://10.0.1.100:3306/sportscars
spring.datasource.username=caradmin
spring.datasource.password=caradmin123

spring.jpa.hibernate.ddl-auto=none
spring.jpa.show-sql=true


Or:

spring.datasource.url=jdbc:mysql://10.0.1.100:3306/sportscars


depending on the driver.

Step 7: Add MariaDB Driver

Maven:

<dependency>
    <groupId>org.mariadb.jdbc</groupId>
    <artifactId>mariadb-java-client</artifactId>
</dependency>

Step 8: Create an Entity
@Entity
@Table(name = "cars")
public class Car {

    @Id
    private Integer id;

    private String make;
    private String model;
    private Integer year;
    private Integer horsepower;
    private Integer topSpeedMph;
    private BigDecimal priceGbp;
    private String engineType;
}

Step 9: Create Repository
@Repository
public interface CarRepository
        extends JpaRepository<Car, Integer> {
}

carRepository.findAll();
